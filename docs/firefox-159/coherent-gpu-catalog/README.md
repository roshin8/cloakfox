# Firefox159 coherent executable GPU catalog

The accepted scope is **coherent executable Apple/Intel/AMD/NVIDIA capability
profiles with canonical rendering**, rather than physical vendor-driver emulation.

The existing default-off `cloakfox.opt.container_rendering_profiles` toggle now
selects a complete catalog cohort. Canonical rendering remains required. The
BrowserForge vendor/renderer identity is preserved; optional capability ceilings
filter eligible cohorts before activation. Two cohorts replace the independently
varied limits: portable4k and desktop8k. Their shader, texture/unit, WebGL2 and
WebGPU buffer/storage resource bounds are enforced in native validation.

Container records and secrets remain separate. Selection uses the existing
container secret, canvas seed and schemeful top-level site with its existing HMAC
domain. Ordinary capability values can coincide across containers; that does not
share an identity record or secret. No secrets are regenerated by migration.
Legacy version1 descriptors are revalidated against the same catalog; new writes
use version2. Invalid ownership, metadata, ceilings or unsupported backing fail
closed. Existing contexts retain their captured profile through settings changes
and context restoration.

The change preserves canonical backend integrity, input ownership/provenance,
precise/PBO readback restrictions, per-container/site noise and protected generic
toggle-off behavior. It adds no network discovery, hardware inventory or media
permissions. It does not promise undetectability, physical-driver equivalence or
identical output across operating systems.

## Evidence

- `build-status.json`: isolated Firefox159 native build, two low-priority jobs.
- `patch-replay.json` / `patch-replay.log`: all161 ordered privacy patches replay.
- `preservation.json`: checkpoint existence, unchanged Chromium build-input key,
  exact native executable/XUL hashes for the separate acceptance app.
- `unit-tests.txt` and `profile-node-tests.txt`: catalog generation/validation,
  native decoding/eligibility, legacy migration and real native GL validation.
- `runtime.json`: fresh headless runtime outcomes; see `run-runtime.py` for the
  explicit test app, owned profiles, native WebGPU headless setting and probes.

The test app is `firefox-src/.tools159/acceptance-coherent-gpu/Cloakfox.app`.
It is a self-contained copy with real canonical backend files, retaining the
normal integrity checks. Personal profiles and installed applications are
unchanged. Chromium inputs/processes and all prior checkpoints are preserved.

The previous investigation and physical-media verification remain recorded in
[the earlier receipt](../gpu-realism-media/README.md). Its unresolved physical
emulation target is superseded here only by the user's explicit scope choice;
no physical-driver validation is claimed.

## Results and limits

The159 build and161-patch replay passed. The four-family profile probe passed
**385 assertions**, with both4k/8k cohorts, full GL tuples, actual resource
boundaries, workers, restoration, v1 metadata, restart and toggle-off controls.
All ten selected graphics integration probes passed. Independent review found
no actionable defects. Targeted Python/native tests passed9tests plus6subtests;
all369Node tests and26Gecko CI helper tests passed. The broader browser-backed
Python suite passed157tests in72.54seconds on the explicit159 acceptance app.

Unchanged CreepJS/FingerprintJS audits executed96library samples across both
canonical modes with WebGPU enabled:472checks in the legacy canvas mode and464
with canonical rendering/profiles, with no acceptance failures. Each used three
reload samples per case, separate containers/sites, return-to-site checks and
native controls. Raw reports stay under the ignored test report directory;
`acceptance.json` records their hashes and paths. Warning extracts are retained.
CreepJS still flags suspicious GPU/capabilities and unknown rotate dimensions;
Chrome-UA cases also retain the engine mismatch. No warnings were hidden and
these tests do not establish universal fingerprint resistance.
