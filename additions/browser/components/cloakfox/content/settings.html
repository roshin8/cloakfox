Frequently asked questions

How does Cloakfox generate an identity?BrowserForge sampling and the choices in Identity generator

Generate and apply creates a fresh BrowserForge identity using the browser, version, operating system and hardware selected above. Apply selected profile uses the deterministic preview with a fresh identity seed.

Can I edit the User-Agent manually?Use a generated identity or override individual browser fields

Yes. Raw User-Agent remains available under Advanced field overrides in Browser fields. Manual values stay pinned when you generate another identity unless you choose to clear existing overrides.

Why can another operating system look inconsistent?Fonts and rendering still come from the computer running Cloakfox

Choosing this computer’s OS reduces font and rendering contradictions. Cross-OS sampling coordinates reported fields, but it cannot reproduce a foreign operating system’s complete renderer.

How Cloakfox works

Cloakfox is a Firefox build, so it always claims to be Firefox. Per-container privacy comes from which Firefox user you appear to be — Mac, Windows, or Linux Firefox with varied hardware, screen, GPU, fonts, and audio characteristics drawn from BrowserForge's real-world joint distribution.

Each container's master seed deterministically samples one fingerprint at first launch. The sample is coherent — webGl renderer matches platform matches screen — so individual fields don't contradict each other. Click Generate new identity to roll a new master seed and draw a new Firefox identity. Click any field below to override that one value while keeping the rest of the persona intact.

We can't credibly spoof as Chrome / Safari / Edge because the JS engine (SpiderMonkey), CSS engine (Gecko) and WebRTC remain Firefox-based. The optional network adapter changes selected TLS and HTTP fields, but full Chrome equivalence is pending. These differences are visible to sophisticated probes. A shallow Chrome UA disguise (for sites that only check the UA string) is a future opt-in feature.
